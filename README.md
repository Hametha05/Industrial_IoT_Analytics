# Industrial IoT Data Pipeline & Machine Analytics System

An end-to-end Industrial IoT project for real-time machine data collection, processing, storage, and analytics.

## 1. Architecture

Machine Simulator → MQTT → Python Consumer → Data Processing → PostgreSQL / Redis / CSV → FastAPI → Streamlit Dashboard + RAG Assistant

## 2. Technologies

Python, MQTT, PostgreSQL, Redis, FastAPI, Streamlit, Pandas, Docker, Google Gemini, ChromaDB.

## 3. Key Features

- Real-time machine monitoring
- Data validation and anomaly detection
- PostgreSQL historical storage
- Redis real-time caching
- Machine-wise CSV storage
- Historical analytics dashboard
- AI-powered RAG Assistant
